# Wild Van T-Shirt Prototype

Static GitHub Pages prototype for the T-shirt storefront.

This snapshot uses the latest radical van design catalog:

- 100 product concepts
- 100 SVG placeholder artworks
- 100 Nombo-ready prompt records
- Static catalog: `products.radical-vans.json`
- Prompt catalog: `prompts.radical-vans.json`

Notes:

- Checkout/Printful fulfillment requires the Python backend and credentials; this GitHub Pages version is for browsing product/design concepts.
- Placeholder SVGs are intentionally rough review art. Final art can be generated later with Nombo and swapped into the catalog.
- No trademarks/logos are included.
